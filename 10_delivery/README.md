## ترتیب اجرا

1. فایل `.gitignore` را در Root پروژه قرار دهید.
2. نام اعضا را در `team_contribution.md` وارد کنید.
3. مشکل نهایی Automation را رفع و اجرای موفق را ثبت کنید.
4. Repository را Initialize کنید.
5. Commitهای معنی‌دار بسازید.
6. اسکریپت تولید خروجی‌ها را اجرا کنید.
7. خروجی‌ها را Commit کنید.
8. Repository را Push کنید.
9. پس از Verification موفق، Tag نسخه `v1.0.0` بسازید.
